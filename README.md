# South African Unemployment Analysis (2008–2025)

## Project Overview
This project analyses unemployment trends in South Africa from 2008 to the third quarter of 2025. It uses provincial and metropolitan unemployment data to explore changes over time, differences between regions, and unemployment trends before and after 2020.

## Tools Used
- Microsoft Excel
- Power Query
- PivotTables and PivotCharts
- Power BI *(used for dashboard development)*

## Key Questions
1. How has South Africa's unemployment rate changed over time?
2. Which provinces had the highest and lowest unemployment rates?
3. How did unemployment change in Gauteng and its major metropolitan areas between 2020 and 2021?
4. How do average unemployment rates compare before, during, and after 2020?

## Key Findings
- The national unemployment rate increased from approximately 22.5% in 2008 to a peak of approximately 34.3% in 2021.
- In the third quarter of 2025, the Eastern Cape recorded an unemployment rate of 41.2%, compared with 19.7% in the Western Cape.
- Average unemployment was approximately 25.5% before 2020, 29.2% during 2020, and 33.1% from 2021 to the third quarter of 2025.

## Data Preparation
Power Query was used to reshape the dataset, handle missing values, standardise province names, assign data types, and create additional fields for analysis.

## Limitations
The 2025 data covers only the first three quarters. The observed trends describe changes in unemployment rates but do not establish the causes of those changes.
